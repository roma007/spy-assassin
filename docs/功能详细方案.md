## 2. 功能一：检查引导（Room Check，默认首页）

**定位**：区别于竞品的核心体验——把零散工具串成 4 分钟流程，降低用户学习成本。

### 2.1 流程步骤（引导式，逐步解锁）
| 步骤 | 动作 | 对应功能 | 预计耗时 |
|---|---|---|---|
| 1 | 视觉排查（镜面 + 高危点） | 内置图文清单 | 1 分钟 |
| 2 | 关闭灯光 → 红外扫描 | 红外检测 | 1.5 分钟 |
| 3 | 连接 WiFi → 设备扫描 | WiFi 扫描 | 1.5 分钟 |
| 4 | 贴近可疑物磁力扫描 | 磁力检测 | 1 分钟 |

### 2.2 交互细节
- 每步完成可勾选 → 全部完成出「检查完成」摘要 + 风险计数
- 任一步发现风险 → 强引导进入「下一步行动」（拍照取证 → 联系前台/房东 → 报警指引）
- 支持跳过任意步骤
- 高危点清单（图文）：烟雾报警器、插座孔、镜子、装饰画、空调出风口、床头电子钟、路由器、花盆、灯具

### 2.3 状态与指标
- 完成率（引导式 → 各工具使用率）
- 平均完成时长目标 ≤ 5 分钟

## 3. 功能二：红外光检测（核心功能）

**原理**：手机 CMOS 对 850/940nm 红外光敏感；夜视摄像头红外补光在屏幕上呈紫色/白色亮点。

### 3.1 使用流程
1. 引导页：提示"关闭灯光、拉窗帘、全黑环境、手机稳定"
2. 相机全屏预览（可切换前后摄，前摄无红外滤片机型更灵敏）
3. 实时检测高亮/红外亮点 → 屏幕叠加红色方框 + 中心放大镜
4. 检测到亮点 → 振动 + 提示"发现疑似红外光源，请物理确认"
5. 排除项提示：电视遥控器（仅在按键瞬间发红外，连续亮点可疑）

### 3.2 算法规格（V1 Dart 版，V2 原生通道）
- 输入：camera 图像流 YUV → 灰度
- 检测：亮斑分割（阈值 + 连通域），过滤条件：
  - 亮度 > 环境均值 × N（N 可调，默认 3）
  - 面积 3~50 px
  - 形状近似圆形（圆度 > 0.5）
- 输出：亮点坐标列表 → UI 叠加层
- 帧率目标：≥ 10 FPS（Dart 版可降；原生版 ≥ 24 FPS）
- 相机帧率 / 分辨率配置：默认 720p / 30fps，可降分辨率提帧率

### 3.3 权限与生命周期
- 相机权限（iOS NSCameraUsageDescription / Android CAMERA）
- 进入页面即申请；退出页面释放相机
- 前后摄切换、闪光灯开关（红外检测建议关闭闪光灯）
- 稳定提示：加速度计检测抖动 → 提示"手机请保持稳定"

### 3.4 风险分级
- 亮点连续存在 2s+ → 高风险（红色）
- 偶发亮点 < 1s → 低风险（黄色，提示可能是遥控器/反光）

## 4. 功能三：WiFi 网络扫描

**原理**：联网摄像头接入同一局域网，通过主机探测 + 端口 + MAC 厂商识别发现可疑设备。

### 4.1 使用流程
1. 检测当前 WiFi 是否已连接（未连接 → 引导先连接）
2. 一键扫描 → 并发探测局域网存活主机
3. 结果列表（按风险分级排序）：
   - IP / 主机名 / MAC（Android）/ 开放端口 / 厂商
   - 已知设备（用户标记过"我的设备"）→ 折叠显示
4. 点击设备 → 详情：端口命中、厂商、风险理由
5. 长按设备 → 标记为已知/可疑/忽略

### 4.2 技术规格
- 子网发现：获取本机 IP/掩码 → 生成网段 → 并发 ICMP/TCP 探测
- 存活判定：`RawSocket` 连接探测（iOS 走原生 Network framework，Android 走 RawSocket / /proc/net/arp）
- 端口指纹：554（RTSP）、80、8080、8000、34567（雄迈）、37777（大华）、9000（小米）、8888（TP-Link 等）
- MAC 厂商库（OUI）：海康、大华、TP-LINK、小米、雄迈、中维世纪、乔安 等本地数据库匹配
- 风险模型：
  - 命中 554 端口 → 高
  - 命中 IP 摄像头常见端口 + 厂商匹配 → 高
  - 未知名主机 + 厂商匹配 → 中
  - 已标记已知 → 不提示
- 扫描并发度：~30 线程，整网段 ≤ 30s

### 4.3 平台差异（重要）
| 平台 | MAC 地址 | 说明 |
|---|---|---|
| Android | ✅ 可读 /proc/net/arp | 需 ACCESS_FINE_LOCATION + ACCESS_WIFI_STATE |
| iOS | ❌ 拿不到 MAC | 仅 IP + 端口 + 主机名；需 NSLocalNetworkUsageDescription |

### 4.4 免责声明
页面固定展示："仅检测当前 WiFi 下的联网设备，离线/本地存储摄像头无法被发现；结果仅供参考，非执法证据。"

## 5. 功能四：磁力检测

**原理**：摄像头内部马达/线圈/电源产生局部磁场，磁力计近距离感知。

### 5.1 使用流程
1. 引导：手机贴近可疑物 3~10cm，缓慢移动
2. 实时数值曲线 + 磁场强度（µT）仪表盘
3. 阈值线（可调，默认 60µT）→ 超过即振动 + 红色提示
4. 提示传感器位置（iPhone 右上角）便于定向

### 5.2 技术规格
- 输入：`sensors_plus` 磁力计流（X/Y/Z）
- 计算：|B| = √(x²+y²+z²)，低通滤波平滑
- 环境校准：进入时采样 2s 基线，读数显示"相对环境增量"降低误报
- 提醒策略：连续 1s 超阈值才触发，避免毛刺

### 5.3 已知限制（页面明示）
近距离（几厘米）才有效；靠墙电子设备密集区域误报多。

## 6. 功能五：镜头反光扫描（V2）

**原理**：镜头镀膜为回反射体，强光沿原路反射，形成高亮圆形光斑。

### 6.1 使用流程
1. 引导：昏暗环境、开启手电（torch 常亮）、手机与光源同轴
2. 缓慢横移扫描墙面/物体
3. 实时检测高亮小圆斑 → 框选 + 提示"疑似镜头，变换角度确认"
4. 误报说明：玻璃、金属、亮漆面均会反光，圆形+小而亮+角度变化时持续存在才是镜头特征

### 6.2 算法规格
- 与红外共用相机管线与亮斑检测内核
- 附加过滤：光斑需持续 ≥ 2 帧且圆形度 > 0.6，尺寸 3~30px
- 手电：`FlashMode.torch`

## 7. 功能六：蓝牙扫描（V2）

### 7.1 规格
- `flutter_blue_plus` 扫描周边 BLE 设备
- 列表：名称 / 厂商前缀 / RSSI（距离指示）
- 风险提示：名称含常见摄像头/录音品牌关键词、无名称未知设备
- 局限说明：摄像头蓝牙使用率低，仅作辅助
- 权限：iOS NSBluetoothAlwaysUsageDescription / Android BLUETOOTH_SCAN

---

## 8. 功能七：检测报告（V2）

### 8.1 报告内容
- 时间戳、酒店/地点（用户输入，非定位）、WiFi 名
- 各检测项结论（通过/存疑/风险）+ 设备明细
- 可疑设备/亮斑截图（用户可拍照存档）
- 下一步行动建议清单

### 8.2 导出方式
- 本地生成 PDF → 系统分享面板（微信/邮件/打印）
- 仅本地生成，不落服务器

## 9. 权限矩阵

| 权限 | iOS Key | Android | 用途 |
|---|---|---|---|
| 相机 | NSCameraUsageDescription | CAMERA | 红外/反光检测 |
| 本地网络 | NSLocalNetworkUsageDescription | — | WiFi 扫描 |
| WiFi 状态 | — | ACCESS_WIFI_STATE / CHANGE_WIFI_STATE | WiFi 扫描 |
| 定位 | — | ACCESS_FINE_LOCATION | Android WiFi 扫描必需 |
| 蓝牙 | NSBluetoothAlwaysUsageDescription | BLUETOOTH_SCAN / BLUETOOTH_CONNECT | 蓝牙扫描 |
| 传感器 | 无需授权 | 无需授权 | 磁力检测 |

**原则**：全部按需申请、首次进入对应功能时申请、拒绝后提供"去设置"引导。

## 10. 数据模型（本地仅内存/可选本地存储）

```dart
class ScanResult {
  final String feature;        // ir / wifi / magnet / bluetooth / lens
  final DateTime time;
  final RiskLevel risk;        // safe / low / high
  final List<DeviceHit> hits;  // 明细

class DeviceHit {
  final String? ip;
  final String? mac;
  final String? hostname;
  final String? vendor;
  final List<int> openPorts;
  final String reason;
  final bool markedKnown;
}
```

## 12. 验收标准（M1~M2 重点）

| 功能 | 验收标准 |
|---|---|
| 红外检测 | 暗房 + 手机摄像头对已知红外灯 → 1s 内框选；误报 < 10%/min |
| WiFi 扫描 | 家庭网络 ≤ 30s 列出全部设备；对路由器/摄像头命中正确端口与厂商 |
| 磁力检测 | 贴近手机充电器 → 数值抬升并触发提醒 |
| 检查引导 | 4 步可勾选流转、可跳过、完成后出摘要 |
