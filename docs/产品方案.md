# 隐藏摄像头检测 App 产品方案

> 项目：隐私相机 App（住酒店 / 在家查找隐藏摄像头）
> 技术栈：Flutter 跨平台（iOS + Android）
> 更新日期：2026-08-11

---

## 1. 产品定位

**「诚实的、专业的、隐私至上的房间隐私检查工具」** —— 不是"神器"，是"带信任感的安心工具"。

核心承诺（护城河）：
- **零数据收集**：无账号、无广告、无云上传，全程本地处理
- **真实算法**：只做真能做到的检测，首页明示"能检测 / 不能检测"，不虚标
- **引导式体验**：4 分钟 Room Check 流程（竞品全是冷冰冰工具列表）

## 2. 市场结论（调研摘要）

### 2.1 需求端
| 区域 | 需求强度 | 关键证据 |
|---|---|---|
| 韩国 | ★★★★★ | molka 危机，每年立案 6000+ 起，2019 CNN 曝光 1600 名酒店客人被直播 |
| 中国 | ★★★★★ | 山东案 10 万条偷拍视频 / 300 摄像头；2025/2 广东率先立法酒店"零偷拍"；"住酒店搭帐篷"网帖 2.8 万赞；33 元探测器卖出 20 万+件 |
| 欧美 | ★★★☆ | 11% 住客在短租发现过摄像头；GDPR 推高隐私意识 |
| 非洲 | ★★ | MEA 仅占 3.5% 份额，支付能力弱，暂不做 |

### 2.2 市场盘面
- 隐藏摄像头探测器硬件市场：$25M (2024) → $70M (2033)，CAGR 15.7%
- 含专业设备总市场：$2.1B (2025) → $3.9B (2034)，CAGR 7.8%
- App 端同质化严重、红海，但头部可赚钱：Peek 月入 ~$200K（年 $2.4M）；大量竞品月下载 <5K
- 付费模式成立：iOS 订阅 $30-40/年可跑通，但依赖"真能抓到 + 不收集数据"的信任

### 2.3 竞品订阅价（iOS 参考）
$4.99/周、$19.99/月、$39.99/年、$59.99/终身；中国区定价需大幅下调。

### 2.4 结论
值得做，前提是差异化定位（真实技术 + 隐私信任 + 中/英/韩出海 + 引导式体验）。
纯跟风做 C 端订阅大概率成为月下载 <5K 的那批。

## 4. 功能分级与边界

### 4.1 MVP（投入 80%）
1. 红外光检测 —— 全黑环境识别红外补光亮点（核心）
2. WiFi 扫描 —— IP 摄像头识别（MAC 厂商库 + 554/80 端口 + 已知/未知区分）
3. 引导式排查指南 —— 4 分钟全屋流程 + 高危点清单
4. 磁力计 —— 近距贴物扫描 + 振动提醒

### 4.2 V2（出海补全）
5. 镜头反光扫描
6. 蓝牙扫描
7. 检测报告导出（时间/位置/设备信息，取证场景）
8. 多语言：英/韩

### 4.3 V3（第二曲线，本期不做）
9. 酒店自查版（B 端，按房间数订阅）

### 4.4 明确不做
- 虚标"检测所有设备"
- 断开可疑设备 WiFi（越权、涉嫌违法）
- 云上传 / 账号体系（破坏零数据收集卖点）
- 广告（损伤信任，竞品最大差评来源）

## 5. 商业化

- **C 端 Freemium 订阅**
  - 免费：基础红外检测 + 指南（限次，如每日 5 次）
  - Pro：$19.99/年（全功能 + 报告导出 + 无限制）
  - 中国区：¥12-18/年 或一次性买断
  - 本期状态：**真实 IAP 已接入**（`lib/core/pro/iap_store.dart`），产品 ID `…pro.monthly` / `…pro.yearly`；本地模拟解锁仅存于 debug 付费墙
- **不做广告**
- **B 端（本期不做）**：酒店自查版，定价锚定"每间房 300-500 元专业设备"的替代方案

## 6. 技术方案（Flutter）

- 依赖：camera / sensors_plus / flutter_blue_plus / network_info_plus / wifi_iot(Android) / intl
- 红外/反光实时像素分析：Dart 版验证 → FFI + C 检测内核（spot_detector 插件，iOS/Android，摄像头采集仍用 camera 插件），已达 ≥24 FPS
- i18n 从第一行代码接入（intl）
- 隐私架构：权限按需申请、扫描数据不落盘
- WiFi 扫描：Android 读 /proc/net/arp + 端口探测；iOS 本地网络权限 + TCP 端口探测（拿不到 MAC）
