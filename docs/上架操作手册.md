# 上架操作手册（App Store 从零到上架，傻瓜式步骤）

> 你已完成的：开发者账号（99 美元年费）已充值、App 代码与商店素材（名称/简介/图标/截图/隐私政策网页）已全部备好。
> 剩下的事全部在这个网站上做：**https://appstoreconnect.apple.com**（苹果官方后台，简称 ASC）。
> 先登录（苹果账号 + 短信验证码），首次登录会让你同意《付费 App 协议》，勾选同意即可。

---

## 第 1 步：注册 App 的身份证（Bundle ID）

App 在苹果后台有个唯一编号，代码里已经定好了：
- Bundle ID = `com.spyassassin.app`

操作：
1. 左菜单选 **证书、标识符与描述文件（Certificates, Identifiers & Profiles）**。
2. 选 **标识符（Identifiers）** → 右上角 **+** 。
3. 选择类型 **App IDs** → 继续。
4. 描述随便填（如 `Spy Assassin`）；Bundle ID 选 **Explicit（显式）**，填 `com.spyassassin.app`。
5. 勾选 **包含推送通知（Push Notifications）可以不勾**；其余默认即可 → 继续 → 注册。
6. 看到列表里有这条记录即成功。

> 如果创建 App 时提示「Bundle ID 已存在」之类，说明你以前注册过，直接到第 2 步用现成的即可。

---

## 第 2 步：创建 App（登记产品）

1. 回到首页 → 点 **我的 App（My Apps）** → 左上角 **+** → **新建 App（New App）**。
2. 按下面填：
   - 平台：**iOS**（如提示可选择，iPhone + iPad 都勾上）
   - 名称：`间谍刺客 - 防偷拍反针孔摄像头检测`（之后还能加英文等语言名）
   - 主要语言：**简体中文**
   - Bundle ID：选 `com.spyassassin.app`
   - SKU：`spyassassin001`
3. 创建后进入 App 详情页，左侧菜单出现「App 信息 / 定价与销售范围 / 准备提交 / 版本 / 媒体管理 / App 内购买项目」等。

---

## 第 3 步：上传截图

1. 左侧选 **版本（当前版本/1.0 准备提交）**。
2. 找到「App 截屏（App Screenshots）」区 → 在 **iPhone 6.9 英寸（1320×2868）** 那一格点 **+**（或拖拽）。
3. 依次把 `docs/screenshots/zh/01_home.png、02_room_check.png、03_wifi.png、04_more.png、05_guide.png、06_privacy.png、07_report.png` 拖进去（顺序 = 显示顺序）。
4. 英文/西语/韩语页面：在顶部把语言切到对应语言后，同样上传对应 `docs/screenshots/en|es|ko/` 里的图（也可以直接共用中文图，省事）。
5. 若后面勾选了 iPad 支持，会多出「iPad 13 英寸」格子，需要再传一套 13" 截图（可稍后补，或用 App 的 iPad 布局模拟截图）。

---

## 第 4 步：填商店文案

对照 **《上架清单.md》** 第 2 节逐格复制：
- 简介（Description）
- 关键词（Keywords）
- 促销文本（What's New / Promotional Text）——App Store 版本信息里的「促销文本」和 6.9" 截图下方填
- 支持网址 / 营销网址 / 隐私政策网址

首次只需把中文默认语言填完即可发布；英文等在页面顶部语言下拉里逐个添加后再填（不是必须，但推荐）。

---

## 第 5 步：创建两个订阅产品（Pro 会员）

1. 左侧 **App 内购买项目（In-App Purchases）** → **+**。
2. 类型选 **自动续期订阅（Auto-Renewable Subscription）** → 继续。
3. 参考名（仅后台可见）填 `Pro Monthly`；产品 ID 填 **`com.spyassassin.app.pro.monthly`**（必须一字不差！）。
4. 订阅组：新建一个组，名字随意（如 `pro`）。
5. 保存后进入该产品详情页：
   - **本地化**：加中文/英文/西语/韩语，各填显示名（见《上架清单.md》§4）。
   - **审阅信息/订阅条款**：填试用与取消说明（示例见《上架清单.md》§6）。
   - **价格**：选一个价格点（如 CN ¥18 / US $2.99），保存。
6. 重复上述步骤，创建第二个：产品 ID `com.spyassassin.app.pro.yearly`，订阅组选**同一个 `pro` 组**，价格选年度档（如 ¥128 / $19.99）。
7. 两个产品状态从「缺少元数据」变为 **已批准（Approved）** 后，App 里的解锁按钮才能真正扣款。

> ⚠️ 产品 ID 与代码里的 `com.spyassassin.app.pro.monthly` / `.yearly` 完全一致才生效。

## 第 6 步：填审核信息

1. **App 信息** → 隐私政策 URL 填 `https://roma007.github.io/spy-assassin/privacy.html`（先做第 7 步让它能打开）。
2. **版本 → App 审核信息（App Review Information）**：
   - 登录：否
   - 备注：`反偷拍检测工具，无账号无内容；检测功能依赖相机/局域网/传感器，请在提供相机权限的真机或允许的网络环境体验；也可仅查看首页与排查指南。`
3. **出口合规（Export Compliance）**：选 **不使用豁免之前的加密（No）** → 继续弹窗答「否」。
4. **年龄分级（Age Rating）**：逐项全部选「否/无」，最终 4+。
5. **版权（版权/侵权）**：填你的主体名称或选不适用。
6. 保存。

## 第 7 步：把隐私政策网页上线（一次，约 5 分钟，全程免费）

隐私政策网页已备好两份：
- `docs/privacy-policy-web/` → 里面有 `index.html`，这个文件夹可直接上传（Cloudflare 方案用这个）
- `docs/privacy.html` → 中英对照同内容，给 GitHub Pages 用

### 方案 A（推荐，国内也能打开）：Cloudflare Pages 拖拽上传

1. 打开 `https://dash.cloudflare.com/` → 用邮箱注册/登录（选 Free 计划即可，**不用绑信用卡**）。
2. 左侧菜单 **Workers 和 Pages（Workers & Pages）** → **创建（Create）** → **Pages** → **上传资产（Upload assets）**。
3. 给项目起个名字（如 `spy-assassin-privacy`）→ 把电脑上这个文件夹拖进去：
   `我的文档/源码/Security Camera/docs/privacy-policy-web/`
   （文件夹里就一个 `index.html`，拖进去即可）
4. 点 **部署（Deploy）**，约 1 分钟完成，得到网址：
   `https://spy-assassin-privacy.pages.dev/`
5. 手机/电脑浏览器打开确认显示「隐私政策 · Privacy Policy」即成功。**把这个网址填进 App Store Connect 的隐私政策 URL。**

### 方案 B：GitHub Pages（也是免费，但国内访问 github.io 有时不稳）

1. ⚠️ 先确认仓库是**公开**的。打开 Settings → 若看到「升级或将此仓库公开以启用页面」，说明仓库当前是**私有**的，需要先：
   仓库 Settings（设置）→ **常规 General** → 滚到底 **危险区域 Danger zone** → **更改仓库可见性 Change repository visibility** → **Public（公开）** → 输入密码确认。
   （公开 = 这个 App 的全部源码对所有人可见；不想公开源码就不要用方案 B。）
2. 打开 Settings → **Pages（页面）** → Source 选 **Deploy from a branch** → 分支 **main** → 目录 **/docs** → **Save**。
3. 等 1~2 分钟，浏览器打开确认能访问：
   - `https://roma007.github.io/spy-assassin/privacy.html`
4. 能打开就把这个网址填进后台第 6 步的隐私政策 URL。

> 两个方案都免费。苹果审核员在海外，方案 B 他们也能正常打开；但为了你自己随时能验证、国内访问更稳，**建议用方案 A**。
> 若都不想用，还可以：Netlify Drop（`app.netlify.com/drop` 拖拽同文件夹，同样免费）或 Gitee Pages（国内，但需实名认证，免费版有部署次数限制）。

> ⚠️ 特别注意：**「只把内容保存在本地」不行**——苹果强制要求隐私政策是一个公网网址，审核员会像普通用户一样在浏览器里打开它。本地保存的 `index.html` 只作备份与预览，上架前仍必须有一个能公开访问的 URL。

---

## 第 8 步：提交审核

1. 「版本」页确认所有必填项打勾（截图、简介、关键词、支持网址、隐私政策、年龄分级、审核信息等）。
2. 建议先 **TestFlight 自测**：点版本页的「TestFlight」标签 → 构建版本（用 Xcode 或 CI 上传 .ipa）→ 真机装一遍确认无崩溃。
   - 如果嫌麻烦，也可以直接提交（代码已在真机 iPhone XS Max 上验证过）。
3. 回到「版本 → 1.0」点 **添加以供审核（Add for Review）** → 确认信息 → **提交（Submit）**。
4. **此版本发布方式**：选 **自动发布（Automatically release this version）** → 审核通过即自动上架。

---

## 第 9 步：提交后盯梢

- 审核通常 1~3 天。进度看「App 状态」或邮箱通知。
- **被拒（Metadata Rejected / Rejected）**：打开「解决中心（Resolution Center）」，按苹果的问题逐条修改后 **重新提交（Submit）**。
- 常见被拒点与应对：
  - 隐私政策 URL 打不开 → 检查第 7 步 Pages 是否部署成功。
  - 截图含第三方品牌/误导信息 → 换用 `docs/screenshots` 自带图。
  - 订阅条款不全 → 按《上架清单.md》§6 补齐两条订阅的条款说明。
- 上架后 App Store 搜索可能需要几小时才收录。

## 附：Android（以后想上 Google Play 再做，本次不做）

- 需先生成一个 **release keystore**（`keytool` 生成），把签名信息写进 `android/app/build.gradle.kts`，再用 GitHub Actions 构建签名 APK/AAB。
- 目前 Android release 仍用 debug 签名，**只能自己安装，不能上架**。需要时我再给你一份完整步骤。
- Google Play 后台另需注册开发者账号（$25 一次性）与隐私政策网址（同一个 `privacy.html` 可直接用）。
